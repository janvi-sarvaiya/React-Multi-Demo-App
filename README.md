<h3>React Multi-Demo App</h3> 
👉 Live Demo :-  https://react-multi-demo.netlify.app/
<h4>A React project showcasing 5 interactive demos in one application:</h4>
<ol>
  <li>User Form with CRUD and Search/Sort Functionality</li>
  <li>Countries Information : Display detailed info on countries, fetched from an API for real-time data</li>
  <li>OTP Generator : Generate OTP with customizable length</li>
  <li>Task Scheduler : Organize tasks with Priority, Date and Scheduling Features</li>
  <li>Invoice Generator : Create invoices with items, prices, Quantity and get Total Amount and also remove Items.</li>
</ol>
<hr>
💻 Tech Stack :-
<ul>
  <li>Frontend Framework: React JS</li>
  <li>Data Handling: Local state or API integration</li>
</ul>
